# Ilustrações dos rankings

Ilustração exibida ao lado do título de cada ranking. Nome do arquivo = slug do ranking:

- `falou-merda.webp` (ou `.png` / `.avif`) — Troféu Falou Merda
- `sabio.webp`
- `bala-do-veio.webp`

Quadrada (ex.: 640×640). O `npm run dev`/`npm run build` detecta os arquivos sozinho; sem arquivo, nada é exibido.
